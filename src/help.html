Quick start

Click New reminder, type your note, and pick a time. If two reminders overlap, ChronoRing will warn you, though both will still ring.

CtrlN New reminder
CtrlEnter Save reminder
Esc Close the form

When an alarm rings

When time's up, a chime repeats until you hit Dismiss, and the reminder pins in orange at the top of the list.

If Focus Assist is on, ChronoRing brings its window to the front instead of sending a standard Windows notification.

Managing reminders

Edit
Update the note or scheduled time.
Dismiss
Silence an active alarm and move it to Finished.
Reschedule
Bring a finished reminder back with a new time.
Delete
Permanently remove a reminder.

Keeping it running

Closing the window hides ChronoRing to the tray, so alarms still ring. Right-click the tray icon for Show ChronoRing, Start with Windows, and Quit. Quit is the only full exit.

If ChronoRing doesn't open at sign-in, check Settings → Apps → Startup and make sure ChronoRing is switched on.
